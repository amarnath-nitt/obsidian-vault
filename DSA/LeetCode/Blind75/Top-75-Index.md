## 🎯 Study Strategy

1. **Easy problems** — Build speed and clean explanations.
2. **Medium arrays, strings, linked lists** — These produce the fastest interview gains.
3. **Medium trees and graphs** — Practice recursion, BFS, DFS, and visited-state handling.
4. **Medium DP/backtracking** — Focus on state definition before code.
5. **Hard problems** — Attempt only after the related Medium pattern is comfortable.

> **Rule of thumb:** If a Hard problem feels impossible, solve two Medium problems from the same pattern first.
