## 🧠 Key Patterns Cheatsheet

| Pattern | Trigger Words | Template |
|---------|--------------|----------|
| Two Pointers | sorted array, pairs, sum | left=0, right=n-1, move based on comparison |
| Sliding Window | subarray, substring, contiguous | expand right, shrink left when invalid |
| Binary Search | sorted, min/max feasibility | lo=0, hi=n, while lo<hi, mid=lo+(hi-lo)/2 |
| BFS | shortest path, level order | Queue + visited set |
| DFS | all paths, connected components | recursive or stack |
| Dynamic Programming | optimal substructure, overlapping | define state → recurrence → base case |
| Monotonic Stack | next greater/smaller element | maintain increasing/decreasing stack |
| Backtracking | combinations, permutations, constraints | choose → explore → unchoose |
