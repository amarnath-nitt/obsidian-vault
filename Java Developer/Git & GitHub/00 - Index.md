## ✅ Quick Checklist

**Beginner:**
- [ ] Can initialize a Git repo (`git init`)
- [ ] Can stage and commit changes (`git add`, `git commit`)
- [ ] Can create and switch branches (`git branch`, `git checkout`)
- [ ] Can push/pull from remote (`git push`, `git pull`)
- [ ] Can set up SSH for GitHub

**Intermediate:**
- [ ] Can merge branches (understand fast-forward vs merge commits)
- [ ] Can resolve merge conflicts
- [ ] Can use `.gitignore` properly
- [ ] Can use `git log` to view history
- [ ] Can clone and fork repositories

**Advanced:**
- [ ] Can use `git rebase` vs `git merge`
- [ ] Can use `git reset` vs `git revert`
- [ ] Can use `git cherry-pick` for selective commits
- [ ] Can use `git stash` for temporary work
- [ ] Can use `git reflog` to recover lost commits
- [ ] Can set up and maintain GitHub workflows

## 🎯 Study Path

1. **Basics:** Init, add, commit, status, log
2. **Branching:** Create, switch, merge branches
3. **Remote:** Push, pull, fetch from GitHub
4. **Conflicts:** Merge conflict resolution strategies
5. **Advanced:** Rebase, reset, revert, cherry-pick
6. **Workflows:** Gitflow, PR-based development
