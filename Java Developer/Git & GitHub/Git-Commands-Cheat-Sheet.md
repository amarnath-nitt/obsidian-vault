# Git Commands Cheat Sheet

Quick reference for common Git commands with flags and examples.

---

## 📝 Git Configuration

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global core.editor "code --wait"
git config --global init.defaultBranch main
```

---

## 📝 Repo Lifecycle

| Action | Command | Description |
|---|---|---|
| **Initialize** | `git init` | Create `.git` folder in current dir |
| **Clone** | `git clone <url>` | Copy remote repo to local |
| **Check status** | `git status` | Show modified/staged/untracked files |
| **View history** | `git log` / `git log --oneline` | Commit history |
| **Add file** | `git add <file>` | Stage a file |
| **Add all** | `git add .` | Stage all changes |
| **Commit** | `git commit -m "msg"` | Commit staged changes |
| **Remove file** | `git rm <file>` | Stage deletion + delete from working dir |
| **Rename file** | `git mv old new` | Stage rename |

---

## 📝 Branching

| Action | Command | Description |
|---|---|---|
| **List branches** | `git branch` | List local branches (no `*` on current) |
| **Current branch** | `git branch --show-current` | Show current branch name |
| **Create branch** | `git branch <name>` | Create new branch (doesn't switch) |
| **Create + switch** | `git checkout -b <name>` / `git switch -c <name>` | Create + switch instantly |
| **Switch branch** | `git checkout <name>` / `git switch <name>` | Switch to existing branch |
| **Delete branch** | `git branch -d <name>` | Delete (fails if unmerged) |
| **Force delete** | `git branch -D <name>` | Delete regardless of merge status |

---

## 📝 Merging & Rebasing

| Action | Command | Description |
|---|---|---|
| **Merge branch** | `git merge <branch>` | Merge into current branch |
| **Rebase onto** | `git rebase <branch>` | Reapply commits on top of branch |
| **Rebase interactive** | `git rebase -i HEAD~N` | Edit last N commits |
| **Abort rebase** | `git rebase --abort` | Cancel and return to pre-rebase state |

---

## 📝 Remote Operations

| Action | Command | Description |
|---|---|---|
| **Add remote** | `git remote add origin <url>` | First time setup |
| **Rename remote** | `git remote rename origin upstream` | Rename remote |
| **Remove remote** | `git remote remove origin` | Remove remote |
| **Show remotes** | `git remote -v` | List remote URLs |
| **Push** | `git push origin main` | Push to branch |
| **Push with upstream** | `git push -u origin main` | Set upstream tracking |
| **Push force** | `git push --force origin main` | Overwrite remote history |
| **Push with lease** | `git push --force-with-lease` | Safer force push |
| **Pull** | `git pull origin main` | Fetch + merge |
| **Rebase pull** | `git pull --rebase origin main` | Fetch + rebase |
| **Fetch only** | `git fetch origin` | Download without merging |
| **Show remote URL** | `git remote get-url origin` | Get remote URL |

---

## 📝 Undoing Changes

| Action | Command | Effect |
|---|---|---|
| **Restore working file** | `git restore <file>` | Discard unstaged changes in working dir |
| **Restore staged** | `git restore --staged <file>` | Unstage file (keep content) |
| **Revert commit** | `git revert <commit-hash>` | Create new commit undoing changes (safe) |
| **Reset soft** | `git reset --soft <commit>` | Move HEAD, keep staged changes |
| **Reset mixed** (default) | `git reset <commit>` | Move HEAD, unstage changes |
| **Reset hard** | `git reset --hard <commit>` | Move HEAD, discard ALL changes (local) |
| **Recover from bad reset** | `git reflog` | See history of HEAD moves |
| **Recover deleted commit** | `git reflog --all` | Find commits even after reset --hard |

---

## 📝 Status Shortcuts

```bash
# Quick checks
git status                          # Working tree status
git diff                            # Unstaged changes
git diff --staged                   # Staged changes
git diff <file>                     | Staged vs unstaged for file
git log --oneline -5                # Last 5 commits
git stash                           # Save uncommitted changes
git stash pop                       # Apply last stash
git stash list                      # List all stashes
```

---

## 📝 Common Two-Line Patterns

```bash
# Typical daily workflow
git status
git add .
git commit -m "descriptive message"
git push origin main

# Typical feature branch workflow
git checkout -b feature/new-feature
# ... make changes ...
git add .
git commit -m "feature: add new capability"
git push origin feature/new-feature
# Pull request on GitHub/GitLab
git checkout main
git merge feature/new-feature  # or via PR

# Typical rebase workflow (before push)
git checkout feature/new-feature
git rebase main   # Update feature with latest main
git push --force origin feature/new-feature  # (or --force-with-lease)
```

## 📝 Git Ignore

```bash
# Create .gitignore
echo "*.class" >> .gitignore
echo "*.jar" >> .gitignore
echo "*.exe" >> .gitignore
echo "/target" >> .gitignore        # Ignore entire directory
echo "!.gitignore" >> .gitignore     # Don't ignore the gitignore itself

# Common entries
/.idea/
/.vscode/
/build/
/gradle/
/*.iml
/hsql/
*.recovery/
```

---

## 📝 Git Aliases (Recommended)

Add to `~/.gitconfig` or run individually:

```bash
git config --global alias.co 'checkout'
git config --global alias.br 'branch'
git config --global alias.ci 'commit'
git config --global alias.st 'status'
git config --global alias.unstage 'restore --staged'
git config --global alias.last 'log -1 --oneline'
git config --global alias.visual '!git core.editor'
```

Now you can use: `git co`, `git br`, `git ci`, `git st`, etc.
