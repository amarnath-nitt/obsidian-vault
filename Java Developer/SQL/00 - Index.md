## 📊 SQL Query Patterns

### Basic Patterns
- SELECT with WHERE, ORDER BY, LIMIT
- INSERT, UPDATE, DELETE operations
- Data type conversions

### Intermediate Patterns
- INNER/LEFT/RIGHT/FULL JOINs
- GROUP BY with HAVING
- Subqueries in WHERE, FROM, SELECT clauses
- UNION and UNION ALL

### Advanced Patterns
- Window functions with OVER clause
- CTEs with WITH clause
- Correlated subqueries
- Performance optimization with indexes

---

## ✅ Quick Checklist

- [ ] Can write all JOIN types (INNER, LEFT, RIGHT, FULL) with examples
- [ ] Can write GROUP BY with HAVING conditions
- [ ] Can write subqueries (correlated and non-correlated)
- [ ] Can write CTEs (WITH clause) and recursive CTEs
- [ ] Can write window functions (ROW_NUMBER, RANK, LEAD, LAG)
- [ ] Can write pagination queries
- [ ] Can explain execution plans and optimize slow queries
- [ ] Can design normalized database schemas (up to 3NF)
- [ ] Can explain ACID properties and isolation levels
- [ ] Can write transactions with proper locking

## 🎯 Study Path

1. **Basics:** SELECT, WHERE, ORDER BY, basic aggregations
2. **Intermediate:** JOINs, GROUP BY, subqueries
3. **Advanced:** Window functions, CTEs, optimization
4. **Database Design:** Normalization, indexing, transactions
5. **Performance:** Query optimization, execution plans
