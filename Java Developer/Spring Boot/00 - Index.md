## ✅ Quick Checklist

- [ ] Can explain IoC, DI, and the Spring lifecycle
- [ ] Can explain auto-configuration and conditional beans (`@ConditionalOnClass`)
- [ ] Can write `@RestController` with validation
- [ ] Can implement global exception handling with `@ControllerAdvice`
- [ ] Can explain N+1 problem and list 3 solutions
- [ ] Can explain `@Transactional` propagation and isolation
- [ ] Can configure Spring Security + JWT authentication
- [ ] Can write unit and integration tests with `MockMvc`
- [ ] Can configure caching with `@Cacheable`
- [ ] Can use `@Async` for async operations
