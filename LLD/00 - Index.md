# LLD — Main Index

The LLD package contains preparation tracks for **Low Level Design** (machine coding) interviews: **Concepts** (OOP & principles), **Design Patterns**, **UML**, **Concurrency**, and **Problems**. Click the checkboxes (`- [ ]` / `- [x]`) to toggle completion status directly in Obsidian!

  - Phases: Object Modelling → Design Principles

### 🟡 Track 2: Design Patterns

  - Entry point: [[Patterns/00 - Index|Patterns Index]]

  - Entry point: [[UML/00 - Index|UML Index]]

### 🟣 Track 4: Concurrency

### 🔴 Track 5: Problems

- [ ] **Problems** — Machine coding problems by difficulty
  - Entry point: [[Problems/00 - Index|Problems Index]]

  - Track progress: tick the checkboxes in the linked index

---

## 📚 Recommended Study Order

1. **Concepts** — master OOP, class relationships and SOLID first
2. **UML** — learn to sketch a class diagram and a sequence diagram
3. **Design Patterns** — one phase at a time (Creational → Structural → Behavioural)
4. **Concurrency** — concepts, then patterns, then multi-threading problems
5. **Problems** — Easy → Medium → Hard, always using the 5-step answer framework
