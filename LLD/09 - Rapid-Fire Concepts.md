# ⚡ Rapid-Fire LLD Concepts

> [!success] What is the main benefit of applying SOLID principles?
> Improved code maintainability, flexibility, and extensibility, leading to more robust and adaptable software.

> [!success] Name a creational design pattern and its purpose.
> **Singleton**: Ensures a class has only one instance and provides a global access point to it.

> [!success] Name a structural design pattern and its purpose.
> **Decorator**: Attaches additional responsibilities to an object dynamically, providing a flexible alternative to subclassing.

> [!success] Name a behavioral design pattern and its purpose.
> **Observer**: Defines a one-to-many dependency so that when one object changes state, all its dependents are notified.

> [!success] What is the "is-a" relationship in OOP?
> Inheritance, where a subclass is a specialized type of its superclass (e.g., `Dog is-a Animal`).

> [!success] What is the "has-a" relationship in OOP?
> Composition, where one class contains an object of another class (e.g., `Car has-a Engine`).

> [!success] Why use an interface instead of an abstract class for a contract?
> Interfaces allow multiple inheritance of type (a class can implement multiple interfaces), promote looser coupling, and define a pure contract without implementation details. Abstract classes can provide partial implementation and state.

> [!success] What is the purpose of a Class Diagram?
> To show the static structure of a system, including classes, their attributes, operations, and relationships.

> [!success] What is the purpose of a Sequence Diagram?
> To show the dynamic interaction between objects in a time-ordered sequence for a specific use case.

> [!success] What does YAGNI stand for?
> You Ain't Gonna Need It. It advises against adding functionality until it is necessary.
