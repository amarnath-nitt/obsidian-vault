## 🧱 The Four OOP Pillars (Quick Reference)

| Pillar | One-liner | Interview Trigger |
|--------|-----------|-------------------|
| **Encapsulation** | Hide state, expose behaviour | "private fields + getters/setters" |
| **Abstraction** | Expose *what*, hide *how* | interfaces / abstract classes |
| **Inheritance** | Reuse via "is-a" | `extends`, shared base behaviour |
| **Polymorphism** | One interface, many forms | overloading / overriding / dynamic dispatch |
