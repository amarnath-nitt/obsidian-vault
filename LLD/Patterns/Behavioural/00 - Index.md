## 🎯 How to choose

| Pattern | Use when… |
|---------|-----------|
| **Iterator** | traverse a collection without exposing its structure |
| **Observer** | one change must notify many subscribers |
| **Strategy** | swap an interchangeable algorithm at runtime |
| **Command** | encapsulate a request (undo, queue, log) |
| **State** | behaviour changes with an object's lifecycle |
| **Template Method** | fix an algorithm skeleton, vary the steps |
| **Visitor** | add operations to stable element types |
| **Mediator** | centralise complex peer-to-peer communication |
| **Memento** | snapshot and restore state (undo) |
| **Chain of Responsibility** | pass a request along handlers until one handles it |
