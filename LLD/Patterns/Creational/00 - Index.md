## 🎯 How to choose

| Pattern | Use when… |
|---------|-----------|
| **Singleton** | exactly one instance is shared globally |
| **Factory Method** | subclasses decide which product to build |
| **Abstract Factory** | you need a **family** of matching products |
| **Builder** | an object has many optional parts / needs a fluent API |
| **Prototype** | creation is expensive — clone an existing instance |
