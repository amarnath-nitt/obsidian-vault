## 🎯 How to choose

| Pattern | Use when… |
|---------|-----------|
| **Adapter** | you must use an incompatible / legacy interface |
| **Bridge** | two dimensions vary independently (avoid class explosion) |
| **Composite** | you have a part–whole tree treated uniformly |
| **Decorator** | you add responsibilities dynamically, same interface |
| **Facade** | you simplify a complex subsystem behind one API |
| **Flyweight** | you need **huge numbers** of similar objects, sharing state |
| **Proxy** | you control access (lazy load, security, caching) |
