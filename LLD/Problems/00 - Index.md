## ✅ How to Answer a LLD Interview Problem

1. **Clarify requirements** — functional + non-functional (scale, concurrency). Ask, never assume.
2. **Identify core entities** — nouns from the requirements become classes.
3. **Design the class diagram** — attributes, methods, and relationships (see [[../UML/00 - Index|UML]]).
4. **Apply design patterns** — pick patterns that remove `if/else` and decouple (see [[../Patterns/00 - Index|Patterns]]).
5. **Implement the core flows** — write clean, compiling code for the main use case; mention extensions for the rest.

> Golden rule: **correct, extensible, readable** beats clever. Finish the happy path first.
