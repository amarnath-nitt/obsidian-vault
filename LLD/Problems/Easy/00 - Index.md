## 🎯 How to choose

| Problem family | The hard part |
|----------------|---------------|
| **State machines** (Vending, Coffee, Traffic Signal) | states own the transitions; illegal moves unrepresentable |
| **Allocation + pricing** (Parking Lot) | spot compatibility, ticket lifecycle, pluggable pricing |
| **Community + fan-out** (Stack Overflow, Task Management) | observer side effects; reputation derived, progress rolled up |
| **Platform plumbing** (Logging) | handler chain + formatter strategy; logging never throws |
