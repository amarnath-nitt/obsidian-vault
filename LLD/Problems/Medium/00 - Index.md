## 🎯 How to choose

| Problem family | The hard part |
|----------------|---------------|
| **Money + state** (ATM, Wallet, Auction) | transactional moves; no half-charge |
| **Matching + allocation** (Car Rental, Hotel, Airline, Restaurant, Concert) | inventory search + hold expiry |
| **Social + fan-out** (LinkedIn, Pub-Sub, Social Network, Library) | observer feeds; derived counts |
| **Games + cache** (Tic Tac Toe, LRU) | win detection; O(1) eviction |
