## 🎯 How to choose

| Diagram | Shows | Use In LLD When… |
|---------|-------|------------------|
| **Class** | Classes, attributes, methods, relationships | Always — the core deliverable |
| **Sequence** | Message flow between objects over time | Explaining a key workflow (e.g. book → pay) |
| **Use Case** | Actors and their goals | Scoping requirements at the start |
| **Activity** | Control flow / business processes | Modelling a multi-step algorithm |
| **State Machine** | Object lifecycle and transitions | Objects with a rich state (order, ATM, elevator) |
